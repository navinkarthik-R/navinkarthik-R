## 🧠 About Me

I'm **Navin Karthik R**, a final-year Electronics & Communication Engineering student at Velammal Engineering College, Chennai. I build web apps and the hardware they talk to: React interfaces on one side, ESP32 and Arduino sensor systems on the other, with Java for data structures and problem solving.

Most of what I've built started at a hackathon or a symposium: an AI-assisted early-screening platform that ranked in the global top 100 at HACKHAZARDS '26, a hazard-detection helmet that won 1st prize at the IETE Symposium, and a pharma reverse-logistics platform built in 24 hours.

- 🎓 **B.E. ECE**, Velammal Engineering College · 2023 – present · **CGPA 8.00**
- 🎯 Open to **Full Stack / Software Developer** roles · 2027 graduating batch
